# Spots 🛹

Discover and share skateboard spots around the world.

## About

Spots is an iOS application designed to help skateboarders find, share and explore skate spots globally.

Users can discover locations through an interactive map, add new spots, share photos and preserve skate culture.

## Features

### MVP

- Interactive map
- User location
- Skate spot markers
- Spot details
- Add new spots
- Upload photos

## Technologies

- Swift
- SwiftUI
- MapKit
- CoreLocation
- Firebase
- MVVM Architecture
